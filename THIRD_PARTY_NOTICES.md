The review snapshot contains the training implementation and the public data recipes needed to reproduce training. It
omits author names, affiliations, contact addresses, repository-owner links, and paper-specific evaluation metadata so
that the code can be inspected without revealing the submitting team.

The upstream framework's top-level demo-data directory is intentionally omitted. It contains unrelated sample records
and media; the CIG-SFT examples used by the recipes remain under `example/data/`.
